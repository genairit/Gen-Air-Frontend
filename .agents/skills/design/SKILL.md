# Design handoff

Read the canonical [design agent](../../../agents/design-agent.md) in full. For this client,
read the current [design language](../../../docs/design-language.md), relevant theme and
component sources, and any approved task-specific design reference. Follow the repository's
[Codex guidance](../../../AGENTS.md).

- Run the design step before implementing client-facing UI. Supply the complete task/card
  requirements, acceptance criteria, attachments, comments, and target screens.
- Return the canonical structured handoff directly to the development agent. If a material
  design decision remains open, identify it precisely; continue independent work while it is
  resolved.
- The design agent reads and specifies. The development agent owns application code and verifies
  the rendered implementation against the handoff.
